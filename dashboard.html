上传附件 · 读取正文并分析
可上传 PDF、DOCX、XLSX、PPTX、TXT、CSV。如果 QQ 没有把文件送到机器人，先把原文件下载到电脑，再从这里选择。
一次最多 3 个文件，单个 10MiB、合计 20MiB；最多提取 45000 字。扫描 PDF、文档内的图片和图表不做识别，请另发清晰截图。旧版 DOC/XLS/PPT、加密文件、压缩包不支持。
文件先在服务器提取文字；点击后，可读文字和补充说明会提交给DeepSeek API 分析并计入用量。
网页上传的结果显示在本页和当天日志，不主动推送 QQ。QQ 文件直发仅在平台传来可下载的原文件时处理。

4 · 发送文字或截图，自动整理
把重要工作通知的文字或截图私聊发给机器人即可。默认回复最多 3 条重点待办及时间，完整分析保留在服务器日志。截图会先识别文字再分析。发送 /today 查看当天重点。
截图支持 PNG、JPEG、WebP；一次最多 4 张，单张不超过 10MB，合计不超过 20MB。模糊或无法确认的内容会标为待确认；无法识别时，请发送清晰原图。合并转发卡片里的图片、GIF 和语音尚未展开；普通文件可使用本页“上传附件”。
分析直接调用 DeepSeek API，将截图和消息正文提交 DeepSeek 处理，按你的 API 账号余额计费。图片通常分“识字”和“分析”两次调用，用量分别记录。原文、原图、识别文字和分析结果保存在服务器。
