# Repository instructions

Read [AGENTS.md](AGENTS.md) and [START_HERE.md](START_HERE.md) first. For a deployment request, follow [AGENT_SETUP.md](AGENT_SETUP.md), execute the authorized steps, and guide the user through the required human steps. Do not stop at giving a list of shell commands when you can perform them.

Use the deployment owner's accounts and configuration. Never copy the maintainer's identity, keys or server settings. Credentials are entered through the interactive server wizard, not pasted into chat or committed to Git.
